# SOMNIA-SOMNIAEXCHANGE AUTO SWAP

## Requirement

- Python 3.x
- Web3.py
- Colorama

## Instalation 

1. Clone repository from GitHub:
```bash
git clone https://github.com/adjiadjo/Somnia-Auto-Swap/
```

2. Install Python 3.x [python.org](https://python.org)
3. Install dependencies:
```bash
pip install -r install.txt
```
Or 
```bash
pip install web3 colorama eth-account
```

## How To Use

1. Run Bot:
```bash
python main.py
```

2. Insert private key (without '0x')
3. Tentukan jumlah putaran swap yang diinginkan
4. Masukkan persentase saldo yang ingin digunakan untuk setiap swap
